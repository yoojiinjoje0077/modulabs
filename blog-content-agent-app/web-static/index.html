웹 버전 · 개인 API 키

사용할 AI 연결

OpenAI, Gemini, Claude 중 하나를 고르고 해당 서비스에서 발급한 본인의 비밀 API 키를 입력하세요. 키는 HTTPS로 이 웹앱의 Render 서버를 거쳐 선택한 AI 회사로 전달되며, 브라우저 저장소나 서버 파일에는 저장하지 않습니다. 생성 요청이 끝나면 입력칸을 비웁니다. 사용 요금은 각 서비스 계정에 청구될 수 있습니다.

공개 웹앱에서는 ChatGPT·Gemini·Claude 구독 로그인 대신 각 서비스의 API 키가 필요합니다. HTTPS 주소에서만 키를 입력하세요.

1 누구에게 쓰나요?

과정이 여러 개라면 한 줄에 주소 하나씩 적어주세요. 글 주제와 관련 있는 과정만 소개합니다.

2 어떤 목소리로 쓸까요?

두 톤 모두 표·리스트로 핵심을 정리합니다. B는 더 편하게 말하지만 확인하지 않은 경험이나 대화는 만들지 않습니다.

3 근거 자료와 추가 조건 선택
선택한 서비스의 API로 기획표와 원고를 작성하며, 톤·구성 보완이 필요하면 추가 요청이 발생합니다.
