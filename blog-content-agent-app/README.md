# 블로그 콘텐츠 에이전트

## 링크만 공유하는 웹 버전

저장소 루트의 `render.yaml`로 Render **Blueprint**를 만들면 이 폴더의 `web_app.py`가 배포됩니다. Render에서 GitHub 저장소를 연결하고 **New → Blueprint**를 선택해 이 저장소를 지정하세요. 배포가 끝나면 Render가 발급한 `https://...onrender.com` 주소를 사용자에게 전달합니다. GitHub Pages 주소에서는 글 생성이 작동하지 않습니다.

웹 사용자는 OpenAI·Google Gemini·Anthropic Claude 중 하나를 선택하고 **해당 회사의 API 콘솔에서 발급한 본인 비밀 API 키**를 입력합니다. ChatGPT·Gemini·Claude의 일반 구독 로그인은 공개 웹 버전에서 지원하지 않습니다. 각 사용자의 API 이용 요금과 모델 권한이 적용됩니다. API 키는 브라우저 저장소나 서버 파일에 저장하지 않고 한 번의 HTTPS 생성 요청에서만 사용합니다. 키가 들어간 화면을 공유 컴퓨터에서 열었다면 사용 후 탭을 닫으세요.

Render 무료 웹 서버는 유휴 시 절전 상태가 되어 첫 접속이 지연될 수 있습니다. 운영용으로 꾸준한 접속이 필요하면 Render 요금제를 검토하세요. 실제 글 생성은 각 API의 요금·검색 기능·권한에 따라 달라지며, 키가 없을 때는 샘플 보기만 가능합니다.

웹 버전의 세 모델 연동은 공식 API 형식에 맞게 구현했지만, **실제 계정의 키로 끝까지 생성하는 검증은 아직 수행하지 않았습니다.** 배포 후 OpenAI·Gemini·Claude 각각 한 번씩 실제 생성과 출처 확인을 거쳐 운영하세요.

아래의 로컬 설치 방법은 기존 설치형 앱용입니다.

홍보 대상과 목적을 입력하고 **버튼 한 번으로 주제별 기획표 → 첫 번째 주제의 블로그 원고**를 만드는 설치형 웹앱입니다. 작업 유형 선택 화면은 없습니다. 화면은 HTML·CSS·JavaScript, 생성 서버는 Python으로 만들었습니다. 파일을 전달받은 사람도 자신의 컴퓨터에서 설치해 사용할 수 있습니다.

## 처음 실행하기

1. [Python 3.10 이상](https://www.python.org/downloads/)을 설치합니다. Windows 설치 시 `Add Python to PATH`를 켜세요.
2. ZIP을 풀고 Windows에서는 `start.bat`를 더블클릭합니다. macOS·Linux에서는 터미널에서 `sh start.sh`를 실행합니다. 첫 실행 때 필요한 Python 패키지 한 개가 설치됩니다.
3. 브라우저가 자동으로 열리지 않으면 `http://127.0.0.1:8765`로 접속합니다.
4. 화면의 **Continue with ChatGPT**를 눌러 본인 계정으로 로그인합니다. 로그인 창에서 이 앱이 ChatGPT 요금제 사용량을 쓰도록 허용합니다.
5. 계정에 `gpt-6-astra`가 있으면 자동으로 선택합니다. 없으면 **사용할 모델** 목록에서 직접 고릅니다. 모델을 바꾸면 결과 품질이 달라질 수 있습니다.
6. **기획표와 원고 한 번에 만들기**를 누릅니다. 화면 아래의 샘플 결과는 입력값을 반영하지 않는 고정 예시입니다.

이전 버전을 실행 중이라면 검은 실행 창에서 `Ctrl+C`로 종료한 뒤 새 ZIP을 풀어 다시 실행하세요. 브라우저 새로고침만으로는 실행 중인 서버 코드가 바뀌지 않습니다.

## ChatGPT 로그인으로 생성하기

각 설치자는 자신의 ChatGPT 계정으로 로그인합니다. 앱은 계정에서 허용된 모델 목록을 보여줍니다. 로그인한 계정의 요금제 사용량과 한도가 적용되며, API 키를 따로 만들 필요가 없습니다. 사용량과 앱별 허용 범위는 [ChatGPT 설정](https://chatgpt.com/settings/usage)에서 확인할 수 있습니다.

이 기능은 OpenAI의 [로컬 오픈소스 앱용 ChatGPT 로그인](https://developers.openai.com/siwc/token-sharing-open-source) 방식을 사용합니다. 웹 검색은 선택한 모델과 계정 정책에 따라 가능 여부가 달라질 수 있습니다. `gpt-6-astra`가 없는 계정에서 다른 모델을 고르면 기존과 같은 품질을 보장할 수 없습니다. 앱의 기획표 → 첫 번째 주제 원고 → 톤·표 점검 로직은 두 로그인 방식에서 같습니다.

로그인 정보는 이 컴퓨터의 사용자별 저장소에 보관하고 배포 ZIP에는 포함하지 않습니다. 로그아웃 버튼은 로컬 연결 정보를 지웁니다. 이 앱은 본인 컴퓨터의 `127.0.0.1`에서 실행해야 합니다.

## API 키로 생성하기 (선택)

ChatGPT 로그인 대신 기존 API 요금 방식으로 실행하려는 경우에만 설정합니다.

1. `.env.example` 파일을 복사해 이름을 `.env`로 바꿉니다.
2. `.env`의 `OPENAI_API_KEY=` 뒤에 본인의 OpenAI API 키를 입력합니다. 계정에서 사용할 수 있는 모델이 다르면 `OPENAI_MODEL`을 변경할 수 있습니다.
3. 서버를 종료하고 `start.bat` 또는 `start.sh`를 다시 실행합니다. 로그인하지 않은 상태에서 화면 오른쪽 위에 `키 입력됨 · 유효성 미확인`이 표시됩니다.
4. 홍보 대상·목적·독자·톤을 입력한 뒤 **기획표와 원고 한 번에 만들기**를 누릅니다. 기획표의 첫 번째 주제를 원고 주제로 자동 전달합니다.

자동 작성은 API 생성 요청을 **기본 2회** 실행합니다. 원고에 표·목록이 빠지거나 B의 말투가 거의 반영되지 않으면 한 번 더 수정 요청할 수 있어 최대 3회가 됩니다. 이 경우 토큰과 웹 검색 사용량이 늘 수 있습니다. 두 결과는 한 화면과 하나의 HTML·JSON·Markdown 파일로 내려받습니다.

홍보할 공식 과정이 여러 개라면 **공식 과정 URL 칸에 한 줄에 하나씩** 입력하세요. 에이전트는 각 과정의 내용을 확인하고 해당 주제와 관련 있는 과정만 골라 소개하도록 지시받습니다. 입력한 모든 링크가 한 글에 들어가는 방식은 아닙니다.

API 키는 브라우저에 입력하거나 배포 ZIP에 넣지 않습니다. `.env`는 로컬 서버에서만 읽습니다. 실제 생성은 [OpenAI Responses API](https://developers.openai.com/api/docs/guides/text)를 사용하며, 공식 자료 확인에는 [웹 검색 도구](https://developers.openai.com/api/docs/guides/tools-web-search)를 요청합니다. API 키 방식에서는 별도 API 요금이 발생할 수 있습니다.

**401 인증 오류가 날 때:** API 키 목록에 보이는 `key_...` 식별자나 트래킹 ID가 아니라, `Create new secret key`로 만든 뒤 한 번 표시되는 **비밀 키 전체 값**을 `.env`의 `OPENAI_API_KEY`에 넣어야 합니다. 키는 채팅이나 제출 파일에 넣지 마세요. `.env`를 고친 뒤 서버를 종료하고 다시 실행하세요. 화면의 `키 입력됨`은 형식만 확인한 상태이며 실제 유효성 검증을 뜻하지 않습니다.

## 화면에서 할 수 있는 일

| 선택 | 결과 |
|---|---|
| 기획표 → 블로그 원고 자동 작성 | 버튼 한 번으로 주제마다 독립된 2열 기획표를 만든 뒤 첫 번째 주제의 정보성 원고까지 작성 |
| 톤 A | 직접 찾아본 정보형. 친근하게 질문을 풀고 공식 조건·예시·표·체크리스트로 정리 |
| 톤 B | 모두연 현장 이야기형. 친구에게 말하듯 장면·반응·이모지를 섞고, 시도·막힘·해결을 표·리스트와 함께 전달 |

결과는 미리보기에서 확인하고 **HTML·JSON·Markdown**으로 다운로드할 수 있습니다. 블로그 글의 `이미지 안내`는 이미지 삽입 위치입니다. 이미지를 실제로 생성하거나 네이버 블로그에 자동 게시하지는 않습니다.

두 톤 모두 `^^` 대신 문맥에 맞는 이모지를 씁니다. B에서는 `ㅠㅠㅠ`, `!!!` 같은 대화체 반응을 자연스럽게 사용할 수 있습니다. 참고 블로그의 문장·인물·대화·사진을 복사하거나 실제로 하지 않은 체험을 지어내지는 않습니다. **데모 보기**에서도 A와 B의 문체 및 표·리스트 구성을 비교할 수 있습니다.

검색량·실적 자료가 있다면 `근거 자료와 추가 조건`을 열어 CSV·텍스트 내용을 넣을 수 있습니다. 실제 조회 조건이 없는 값은 `미확인` 또는 `미산정`으로 두도록 설계했습니다. 기획표의 예상 유입은 확정 방문자 수가 아닙니다.

## 제출 및 다른 사람에게 전달

이 폴더 전체를 ZIP으로 전달하면 됩니다. **`.env`, `.venv`, 로그인 저장 파일은 ZIP에 넣지 마세요.** 받는 사람은 Python과 자신의 ChatGPT 계정으로 실행할 수 있습니다. 계정이 지원하지 않는다면 데모 모드로 화면을 볼 수 있습니다.

이 패키지는 로컬에서 실행하는 웹앱입니다. 플러그인이나 ChatGPT GPT 등록이 없어도 쓸 수 있습니다. 브라우저는 `127.0.0.1`의 로컬 서버에만 연결하며, 실제 생성 요청을 누른 경우 입력한 홍보 정보와 근거 자료가 OpenAI API로 전송됩니다. 개인 정보나 비밀 자료는 입력 전에 확인하세요.

## 파일 구성

- `static/index.html`, `style.css`, `app.js`: 입력 화면, 미리보기, 다운로드
- `server.py`: 입력 검증, API 호출, 결과 HTML 작성, 데모
- `chatgpt_auth.py`: ChatGPT 로그인, 세션 갱신, 계정별 모델 조회
- `agent-instructions.md`: 검색 근거·톤·원고 작성에 관한 에이전트 지침
- `.env.example`: 선택적 API 키 설정 예시. 실제 키는 포함하지 않음
- `start.bat`, `start.sh`: 설치 및 실행

## 한계와 검증

- 웹 검색으로 네이버 검색광고·Google Ads 계정의 비공개 검색량을 조회할 수는 없습니다. 실제 CSV를 제공해야 수치에 반영합니다.
- 모든 출처·가격·신청 조건은 게시 전 사람이 다시 확인해야 합니다.
- 데모 모드와 로컬 서버는 로그인 없이 검증할 수 있습니다. 실제 로그인·AI 생성은 설치자의 ChatGPT 계정에서 최종 확인해야 합니다.
